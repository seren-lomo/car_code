# 航向故障快照调试

当前底盘使用 F6 速度模式。Keil 命中断点或手动暂停主控时，电机仍可能执行最后一次速度指令；主控也无法处理按键、串口 STOP 和状态查询。调试时先切断电机动力，再操作调试器。运动期间清除全部断点，不要单步或暂停主控。

`chassis_heading_fault_snapshot` 自动在航向控制器进入故障时保存数据，随后沿用原有逻辑向四轮发送停止指令。它不增加电机端通信超时保护，不能让暂停中的主控自动发送停车指令，也不能保证断线电机收到停车指令。

## 使用步骤

1. 切断电机动力，重新编译、烧录，清除全部断点。
2. 保持主控运行，确认电机测试环境安全后恢复电机动力，重新上传并启动低速路线。
3. 等车辆自行停车后，在 Watch 展开 `chassis_heading_fault_snapshot`，无需暂停主控。
4. 只有 `valid=1` 才存在故障快照；快照保留至主控复位或下一次故障覆盖。`tick` 是故障时的主控毫秒计数，不是实时更新的值。

## 字段

| 字段 | 含义 |
|---|---|
| `fault` / `fault_address` | 底盘故障码 / 故障电机地址，8 为航向保护，地址 0 为整车故障 |
| `action` | 0 单段平移、1 原地转向、2 连续路径 |
| `target_yaw_deg` / `yaw_deg` | IMU 原始角度下的目标航向 / 故障采样航向，不是地图航向 |
| `yaw_error_deg` | 纠偏误差，平移时正数需要左转，负数需要右转 |
| `correction_rpm` | 停止前最近一次计算的纠偏量，正数左转、负数右转；四轮限幅后实际修正量可能更小 |
| `address[4]` | 四轮 CAN 地址，正常为 `{1,2,4,3}`，顺序是左前、右前、左后、右后 |
| `forward_sign[4]` | 各轮前进方向映射，当前为 `{1,-1,1,-1}` |
| `imu_yaw_sign` | 本次动作实际使用的 IMU 方向系数，当前为 -1 |
| `command_rpm[4]` | 停止前最近一次计算的电机有符号转速；可能尚未全部下发或同步执行 |
| `feedback_rpm[4]` | 对应电机最后收到的有符号转速，索引顺序同 `address[]` |
| `feedback_age_ms[4]` | 转速反馈距故障时刻的毫秒数；4294967295 表示未收到反馈 |
| `motor_flags[4]` | 对应电机最近一次状态标志 |
| `pending_address` / `pending_function` | 故障发生时正等待回复的电机地址 / 指令号；它们本身不表示该电机故障 |

先确认反馈是否新鲜，再比较指令与反馈；加减速期间和同步发送过程中，指令与反馈可以暂时不同。编码器反馈正常也不能证明轮子没有在地面打滑。

本次修改仅保存故障证据，未修改轮子映射、IMU 符号、速度、纠偏增益或 20° 保护阈值。
